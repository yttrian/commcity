# CommCity

CommCity is a self-hosted web application for managing character references, artist profiles, and commission proposals.

## Development

1. Install PHP 8.4 and Composer in WSL
2. Run `composer install`
3. Configure the [Laravel Sail](https://laravel.com/docs/12.x/sail) shell alias:
   `alias sail='sh $([ -f sail ] && echo sail || echo vendor/bin/sail)'`
4. Run `sail up` and `sail pnpm dev` (you will need to `sail pnpm i` before the first run)

## Deployment

The easiest way to deploy CommCity right now is using [Dokku](https://dokku.com/).

1. Create a new Dokku app for CommCity and attach a MariaDB service as `DATABASE_URL`
    - `dokku apps:create commcity`
    - `dokku mariadb:create commcity`
    - `dokku mariadb:link commcity commcity`
2. Using `dokku config:set commcity`
    - Set `APP_DEBUG=false` and `APP_ENV=production`
    - Set `APP_NAME` to whatever you want
    - Set `APP_KEY` with a value generated by `php artisan key:generate --show`
3. Set the domain and SSL certificate for the app
4. If using [Cloudflare Tunnels](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/),
   you will need to configure `X-Forwarded-*` headers
    - `dokku nginx:set commcity x-forwarded-for-value '$http_x_forwarded_for'`
    - `dokku nginx:set commcity x-forwarded-port-value '$http_x_forwarded_port'`
    - `dokku nginx:set commcity x-forwarded-proto-value '$http_x_forwarded_proto'`
5. Push your app
    - Optimized route, view, and events will be generated. Config is skipped because it does not work right with Dokku.
    - Database migrations will be automatically applied during release. Backups are encouraged.
    - The default Docker network will be trusted by `TrustProxies`.
